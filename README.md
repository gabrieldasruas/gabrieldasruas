### 🚀 Projeto principal: [Oraklo](https://github.com/gabrieldasruas/oraklo)

Plataforma de prospecção B2B: encontra empresas por mapa e raio a partir da base pública de CNPJs, organiza os leads num pipeline e faz o contato por e-mail, WhatsApp e IA.

- Busca avançada por mapa, CNAE, porte e capital, com perfil de cliente ideal que aprende com o uso
- Pipeline de vendas com score de leads, tarefas, notas e reuniões (Google Agenda / .ics)
- Disparo de e-mails com follow-up automático e rastreio de abertura
- Mensagens escritas com IA (Claude) e integração direta com o RD Station CRM
- Relatórios, planos com limites de uso e páginas públicas de consulta de CNPJ

`Next.js 16` `React 19` `TypeScript` `Tailwind CSS 4` `Supabase (Postgres)` `Vercel`
